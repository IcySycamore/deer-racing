# 🦌 荣耀赛鹿 · 多人竞技

实时多人赛鹿竞猜游戏：驯养神鹿 · 多人同场竞技 · 下注争冠。

基于 **Node.js + Express + Socket.IO** 的实时 Web 游戏，前后端原生 JavaScript，无构建工具。

## ✨ 玩法

- 🏠 **创建/加入房间**：邀请好友同场竞技（需登录账号）
- 🦌 **驯养神鹿**：商店买鹿、训练提升属性、查验、改名、收割鹿茸换金币
- 🥬 **鹿圈养成**：点击抓住鹿、两只鹿配种繁殖小鹿、喂养成年
- 🏁 **实时比赛**：短距 / 耐力 / 障碍三种赛道，LiveView 动画直播
- 💰 **投注竞猜**：独赢 / 位置 / 连赢 / 三重彩，动态赔率
- 🏪 **出租市场**：挂鹿出租赚租金，租用他人神鹿参赛

## 🚀 快速开始（本地）

```bash
npm install
node server.js
# 打开 http://127.0.0.1:50865
```

## 🌐 部署

本项目需要**常驻进程 + WebSocket**，无法用纯静态托管（GitHub Pages / Gitee Pages）。

推荐 **Render / Railway / Fly.io**（免费层）或 **腾讯云/阿里云轻量服务器**。

完整步骤见 **[DEPLOY.md](./DEPLOY.md)**。

关键环境变量：

| 变量          | 作用                                         |
| ------------- | -------------------------------------------- |
| `PORT`        | 监听端口（平台自动注入）                     |
| `HOST`        | 绑定地址，托管平台必须设 `0.0.0.0`           |
| `DATA_DIR`    | 账号存档目录（指向持久化卷，否则重启丢数据） |
| `ADMIN_USERS` | 服主账号名单（逗号分隔），可发布全服通告     |

## 📂 结构

```
server.js           服务器主文件（所有 socket 事件 + 比赛调度）
server/accounts.js  账号存储（盐哈希密码 / 存档）
server/race-engine.js  纯比赛引擎（位置步进 / 判定，可单测）
public/             前端（index.html + css + js 原生模块）
public/js/game-config.js  游戏平衡配置（前后端唯一事实源）
```

## 🔐 说明

- 匿名账号不能创建/加入房间，需登录账号。
- 密码使用 **SHA-256 加盐哈希** 存储。
- 服主通过 `ADMIN_USERS` 环境变量指定。
